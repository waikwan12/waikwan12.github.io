# 日拱一卒 · 个人任务与成长看板

独立静态页面，无构建步骤、数据库、账号、追踪脚本或外部运行依赖。

入口：`/tasks/`。网站主页只增加一个导航链接，原有内容和资源路径保留。

## 可以做什么

- 添加、修改、删除任务，填写计划日期和预计用时。
- 勾选或撤销完成，查看今日任务、全部任务、搜索及状态筛选。
- 按课程、论文、健康语言、工作生活管理阶段目标。
- 自行添加、修改、删除和完成里程碑；进度按完成数/总数计算。
- 任务可选关联里程碑，状态双向同步，一次行动只计一次。
- “沿用安排”将最近一天的任务复制到今天，防止重复添加；新任务从未完成开始。
- 查看本周图表、连续行动天数、12周打卡热力图和每日记录。
- 演示模式使用隔离的内存数据，退出后恢复个人记录。
- 导出JSON备份；导入前校验格式、展示确认，并下载当前看板备份。
- 手机端布局、键盘导航、原生模态框、减少动画偏好支持。

## 数据和隐私

公开源码只有通用示例。个人计划、训练数字、客户信息等请在浏览器编辑或从本机导入，**不要提交个人备份到公开仓库**。

本地存储键：`waikwan.growth-journal.v1`。记录属于当前浏览器和当前网站来源，不自动跨设备同步；切换浏览器、域名或端口，看到的记录可能不同。清除浏览器数据会删除记录，请定期导出。

本地存储没有加密，同一网站来源下的其他脚本也可能访问它。本页面不提供身份认证或私密云同步。

进度初始为零，已学内容可以填入“当前起点”。目标进度与每日打卡分开；增加或删除里程碑会改变百分比的分母。删除已完成事项保留其完成历史；撤销完成则取消对应完成记录。

日期按Asia/Shanghai计算。连续天数允许从昨日开始计算，避免当天尚未完成任务就立刻归零。预计分钟数只表示计划用时，不作为真实专注时长。

## 部署与本地预览

把整个`tasks`目录放到现有网站发布目录中，访问`https://你的域名/tasks/`即可。

本地预览：在网站根目录执行`python -m http.server 8765 --bind 127.0.0.1`，打开`http://127.0.0.1:8765/tasks/`。

不建议把本地双击HTML、临时预览端口作为长期数据保存入口。正式使用固定网站地址，迁移前导出、迁移后导入。
